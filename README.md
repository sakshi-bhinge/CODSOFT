# 💻 CODSOFT C++ Projects

This repository contains a collection of **beginner-friendly C++ console projects** developed during my **CODSOFT internship**.

These projects helped me practice fundamental C++ programming concepts such as user input, conditional statements, loops, functions, and basic problem-solving.

## 📂 Projects

### 1. 🎯 Number Guessing Game

A simple console-based game where the user tries to guess a randomly selected number.

**File:** `Number Guessing Game.cpp`

### 2. 🧮 Simple Calculator

A basic calculator program that performs common arithmetic operations based on user input.

**File:** `Simple Calculator.cpp`

### 3. ✅ To-Do List

A simple console-based application for managing tasks and practicing basic programming logic.

**File:** `To Do List.cpp`
